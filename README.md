# PatchAndShip

We fix security holes in Lovable, Bolt, Replit and Cursor apps on Supabase (database rules, storage buckets, leaked keys, env vars, auth redirects) and deploy them. Within 48 hours of working access or a full refund if you ask within 14 days.

Not sure where your app stands? Start with the free check at https://patchandship.com/#free-check. It reads your public homepage, its JS files and its headers, looking for exposed keys and missing security headers. It doesn't touch your database.

Free resource: [Supabase security checklist](https://github.com/patchandship/supabase-security-checklist)

Not affiliated with Supabase.
